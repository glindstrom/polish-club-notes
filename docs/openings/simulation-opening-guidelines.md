# Opening Guidelines – Simulation-Based

These rules are derived from IMP simulations and indicate when opening is profitable with borderline hands. Thresholds apply non-vulnerable vs. non-vulnerable unless otherwise stated.

**Quick Tricks (QT):** Ace = 1, King = 0.5, KQ = 1, AQ = 1.5

---

## Positions 1 & 2

### Balanced Hands (min 11 HCP)

| Shape | Requirement | Decision |
| ----- | ----------- | -------- |
| 4432 with major | QT ≥ 1.5 | Open |
| 4432 with major | QT < 1.5 | Pass |
| 5332 with major | QT ≥ 1.5 | Open |
| 5332 with major | Otherwise | Pass |
| 4333 | — | Always pass |
| Any, ≥ 12 HCP | — | Always open |

### Unbalanced Hands (min 10 HCP)

#### 5-5 Hands

| Shape | Decision |
| ----- | -------- |
| 5m–5M | Open |
| 5M–5M | Open (positive; needs more deals to confirm) |
| 5m–5m | Pass |

#### 5–4 Two-Suiters

Rules are by two-suiter family (whether the 5-card and 4-card suits are majors or minors), not by remainder shape (5431 / 5422 / 5440).

| Shape | Requirement | Decision |
| ----- | ----------- | -------- |
| 5M–4M | — | Always open |
| 5M–4m | 11+ HCP | Open |
| 5M–4m | 10 HCP, position 1 | Open |
| 5M–4m | 10 HCP, position 2 | Pass |
| 5m–4M | 11+ HCP | Open |
| 5m–4M | 10 HCP | Pass |
| 5m–4m | 11+ HCP | Open |
| 5m–4m | 10 HCP | Pass |

No QT or HLD gate on 5–4 two-suiters.

#### 6-Card Hands

| Shape | Requirement | Decision |
| ----- | ----------- | -------- |
| 6♦ / 6♥ / 6♠ | — | Always open at the 1-level |
| 6♣ | QT ≥ 2.0 | Open |
| 6♣ | QT < 2.0 | Pass |

## Position 3

Same rules as positions 1 & 2 with all HCP requirements reduced by 1. The 5M–4m 10 HCP position-1 exception is not reduced further: in position 3, open 5M–4m from 10 HCP (not 9).

## Position 4 (Fourth Seat)

These rules apply to balanced hands.

### 10 HCP → Always pass

### 11 HCP → Selective opening

Open only with the following hand types (IMP NV):

| Hand type | IMP NV | Decision |
| --------- | ------- | -------- |
| 5-card ♥ + 3+ spades | +1.42 | Open |
| 5-card ♠ | — | Open |
| 4–4 in both majors | +0.78 | Open |
| 5-card ♥ + 2 spades | +0.32 | Borderline — pass recommended |
| All other | negative | Pass |

**Rule of thumb:** Open with 11 HCP if you hold a 5-card ♥ with 3+ spades, a 5-card ♠, or 4–4 in the majors.

### 12–13 HCP → Always open

The only exception tested (12 HCP, 4–4 in minors) is statistically break-even — opening incurs minimal loss and is acceptable.
