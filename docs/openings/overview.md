# Opening Bids Overview

### Description

Opening bids in the Polish Club system:

| Opening     | Meaning                                          |
| ----------- | ------------------------------------------------ |
| 1♣          | (11)12–14 balanced, or 15–17 5+♣, or 18+ any        |
| 1♦          | (11)12–17: 5+♦, any 4♦441, or 4♦ 5♣ (12–15)    |
| 1♥/1♠       | (11)12–17, 5+ cards                              |
| 1NT         | (14)15–17(18) balanced                           |
| 2♣          | 11–14/15: 6+♣ or 5+♣ with 4-card major          |
| 2♦          | (5)6–10: 6+ cards in one major                   |
| 2♥          | (5)6–10: 5♥ + 4+m (5+m vul)                     |
| 2♠          | (5)6–10: 5♠ + 4+m (5+m vul)                     |
| 2NT         | 21–22 balanced                                   |
| 3♣/3♦/3♥/3♠ | Preemptive, 6+ cards                            |
| 3NT         | 1st/2nd seat: Gambling; 3rd/4th: To play         |
| 4♣/4♦/4♥/4♠ | Natural, preemptive                             |
